# X Sheets

트위터(X)의 타임라인과 알림을 스프레드시트 화면으로 바꿔서 읽는 Chrome 확장입니다.
글은 한 줄이 한 행이 되고, 이미지는 기본적으로 표시하지 않습니다.

버전은 `대.중.소` 형식입니다 — 대: 디자인 큰 변경, 중: 중요한 기능 추가,
소: 자잘한 버그 수정. 자세한 내용은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.

## 설치

**이 저장소를 직접 내려받아 설치하는 경우** ([릴리즈 페이지](https://github.com/yhw9906/x-sheets/releases/latest)의 Assets에서 zip을 받으신 경우)

1. zip 파일의 압축을 풉니다. `x-sheets-1.4.0` 같은 이름의 폴더가 하나 생깁니다.
   그 폴더를 열었을 때 `manifest.json` 파일이 바로 보이는지 확인하세요.
2. Chrome 주소창에 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 들어있는
   그 폴더를 고릅니다.
5. `https://x.com` 에 들어가면 표 화면이 뜹니다.

**이미 이 폴더를 코드로 갖고 계신 경우**: 2번부터 그대로 따라 하시고, 4번에서 이
`x-sheets` 폴더를 고르면 됩니다.

새 버전이 나오면 제목 표시줄이나 설정 창에 "새 버전 받기" 링크가 뜹니다. 눌러서
[릴리즈 페이지](https://github.com/yhw9906/x-sheets/releases/latest)로 이동한 뒤,
같은 방법으로 새 zip을 받아 폴더를 다시 로드하면 됩니다.

## 화면 구성

| 자리 | 내용 |
| --- | --- |
| 제목 표시줄 | 현재 보고 있는 화면 이름 |
| 메뉴 표시줄 | 홈, 탐색, 알림, 쪽지, 북마크, 프로필 이동, 글쓰기 |
| 도구 모음 | 찾기, X 검색, 앞뒤 이동, 새로 읽기, 확대 비율, 자동 줄 바꿈, 프로필 사진, 게시물 미디어, 광고 처리, 정렬 해제, 더 불러오기, CSV 저장, 원본 보기 |
| 수식 입력줄 | 선택한 칸의 위치와 전체 내용 |
| 표 | 열 머리글(A, B, C ...)과 행 번호 |
| 상태 표시줄 | 시트 탭, 읽어온 행 수, 정렬 상태 |

### 열 구성

타임라인: 작성자, 계정, 내용, 시간, 답글, 재게시, 마음, 조회, 내 반응, 미디어, 링크
알림: 보낸사람, 내용, 시간, 내 반응, 미디어, 링크

**내 반응** 열에는 이 계정으로 좋아요 또는 리트윗을 눌렀는지가 표시됩니다.

비공개(잠금) 계정의 글은 **작성자** 칸의 색이 옅은 회색으로 다르게 표시됩니다.
광고·프로모션 게시물은 설정에 따라 회색으로 표시되거나 목록에서 아예 빠집니다("광고"라고만
짧게 뜨는 것과 "프로모션"이라고 뜨는 것 모두 같은 설정 하나로 처리됩니다).

인용 리트윗은 **내용** 칸 안에서 인용한 원본 글의 작성자·계정·시간·본문·미디어까지 모두
구획을 나눠 보여줍니다. 전체는 지금처럼 하나의 옅은 회색으로 통일되어, 바깥 글 내용과
한눈에 구분됩니다. 인용된 사진/영상도 "게시물 속 사진/영상" 설정이 `숨김`이 아닐 때
함께 보입니다.

### 새 글 작성

메뉴 표시줄 오른쪽의 **글쓰기** 버튼을 누르면 시트 테마의 작성창이 뜹니다. 글을 쓰고
**게시**를 누르면 X의 실제 글쓰기 버튼을 대신 눌러 작성창을 열고, 쓴 내용을 넣은 뒤
게시 버튼까지 대신 눌러줍니다. 인용 리트윗 작성과 같은 방식이며, X 화면으로 넘어가지
않고 시트 안에서 끝납니다.

### 홈 화면의 추천 / 팔로우 중

홈 화면(추천 / 팔로우 중 탭이 있는 곳)에서는 화면 아래 상태 표시줄에 엑셀 시트 탭처럼
두 개의 탭이 뜹니다. 다른 탭을 누르면 실제 X의 탭도 같이 눌러서 원본 페이지와 어긋나지
않게 하고, 각 탭에서 모은 글은 서로 섞이지 않고 따로 보존됩니다 — "추천"을 한참 보다가
"팔로우 중"으로 옮겨도, 다시 "추천"으로 돌아오면 예전에 모아둔 내용이 그대로 남아 있습니다.
홈이 아닌 다른 화면(알림, 검색 결과 등)에서는 예전처럼 탭이 하나만 뜹니다.

### X 검색

시트가 화면 전체를 덮고 있어서 X의 원래 검색창을 직접 누를 수 없습니다. 그 대신 도구
모음에 이름 상자처럼 생긴 **검색** 칸이 있습니다. 여기에 검색어를 쓰고 Enter를 누르면
X의 실제 검색창에 대신 입력하고 Enter까지 눌러서 진짜 검색을 실행합니다. 검색 결과
화면도 똑같이 표로 볼 수 있습니다.

## 조작

| 동작 | 방법 |
| --- | --- |
| 칸 이동 | 방향키, PageUp, PageDown, Home, End |
| 범위 선택 | 드래그, Shift + 클릭, Shift + 방향키 |
| 열 전체 선택 | 열 머리글 클릭 |
| 행 전체 선택 | 행 번호 클릭 |
| 정렬 | 열 머리글 클릭(오름차순, 내림차순, 해제 순서로 바뀜) |
| 열 너비 조절 | 열 머리글 오른쪽 경계를 드래그 |
| 복사 | Ctrl + C (탭으로 구분한 값) |
| 원본 글 열기 | Enter 또는 칸 두 번 클릭 |
| 찾기 | 도구 모음의 입력칸 |
| 좋아요 · 리트윗 · 인용 리트윗 | 행을 우클릭 |

### 좋아요, 리트윗, 인용 리트윗

행을 우클릭하면 뜨는 메뉴에서 **좋아요**, **리트윗**, **인용 리트윗 작성**을 고를 수 있습니다.
링크를 열어서 대신 눌러야 하는 게 아니라, 시트 화면 뒤에 있는 실제 X 페이지의 버튼을
직접 눌러서 처리합니다.

- **좋아요, 리트윗**: 누르는 즉시 실행됩니다(리트윗은 X가 띄우는 확인 메뉴에서 알맞은
  항목을 대신 골라줍니다). 이미 눌렀던 글이면 취소로 바뀝니다.
- **인용 리트윗**: 시트 테마의 작은 작성창이 뜹니다. 원본 글 요약을 보면서 코멘트를
  쓰고 **게시**를 누르면, 그 내용을 X의 실제 인용 작성창에 대신 입력하고 게시 버튼까지
  대신 눌러줍니다. X 화면으로 넘어가지 않고 시트 안에서 끝납니다.

**알아둘 점**: 이 기능은 지금 실제 X 페이지에 그 글이 화면 요소로 남아 있을 때만 동작합니다.
시트에서 한참 위로 스크롤한 오래된 글은 실제 페이지에서는 이미 사라졌을 수 있어
"원본 글을 찾을 수 없습니다" 안내가 뜰 수 있습니다. 그럴 때는 원본 페이지를 조금
스크롤해서 그 글을 한 번 화면에 보이게 한 뒤 다시 시도해 주세요. 또한 X가 버튼의
내부 구조(data-testid)를 바꾸거나, 인용 작성창의 입력칸에 자동으로 글자를 넣는 방식
(`execCommand`)을 X 쪽에서 다르게 처리하면 동작하지 않을 수 있습니다. 이럴 때는
게시 버튼을 찾지 못했다는 안내가 뜨고, X의 작성창은 열린 채로 남으니 그 자리에서
직접 마무리하면 됩니다.

## 설정

확장 아이콘을 누르면 설정 창이 열립니다.

- **시트 화면 사용**: 끄면 원본 X 화면으로 돌아갑니다.
- **자동 줄 바꿈**: 끄면 한 행이 한 줄로 유지됩니다.
- **자동으로 더 읽기**: 표 아래에 닿으면 원본을 대신 스크롤해 다음 글을 읽어옵니다.
- **확대 비율**: 75 ~ 150%.
- **보관 행 수**: 이 수를 넘으면 오래된 행부터 버립니다.
- **한 번에 불러올 개수**: 더 불러오기 한 번에 목표로 하는 새 글 개수. 20/40/80/150 중 선택(기본 40).
- **프로필 사진**: `숨김` 또는 `작게`(16px). 작성자 칸 옆의 아주 작은 프로필 사진입니다.
- **게시물 속 사진/영상**: `숨김`(기본값) / `작게`(16px) / `미리보기`. 프로필 사진과는
  별개 설정입니다. `미리보기`를 고르면 미디어 칸이 넓어지면서 사진은 정방형으로 크게,
  움짤·동영상은 음소거 자동재생(반복)으로 보여줍니다. 단, 영상 재생 주소를 실제로
  가져올 수 있을 때만 재생되고, 그렇지 않으면 첫 장면 이미지만 보입니다.
- **광고/프로모션 게시물**: `그대로 보기` / `회색 처리`(기본값) / `목록에서 제외` 중 선택. 도구 모음에서도 바로 바꿀 수 있습니다.

## 새 버전 확인

제목 표시줄에 지금 설치된 버전이 표시됩니다. 6시간에 한 번, GitHub의 공개 릴리즈 정보
(`api.github.com`)를 확인해서 더 새 버전이 있으면 제목 표시줄과 설정 창에 "새 버전
v#.#.# 받기" 링크가 뜹니다. 눌러보시면 다운로드할 수 있는 릴리즈 페이지로 이동합니다.

이 확인 과정에서 X 계정 정보나 시트에 모은 어떤 데이터도 어디로도 보내지 않습니다.
GitHub의 공개 API에서 최신 버전 번호만 익명으로 조회합니다. 이 기능을 위해
`https://api.github.com/*` 접근 권한이 추가되었고, 확장이 통신하는 곳은 X(x.com,
twitter.com)와 이 GitHub API, 이렇게 두 곳뿐입니다.

## 동작 방식

원본 페이지는 그대로 두고 그 위에 표 화면을 덮습니다. `MutationObserver`로 X가 그리는
`article` 요소를 지켜보다가 값을 뽑아 행으로 쌓습니다. 표 아래에 닿으면 원본 페이지를
대신 스크롤해 다음 글을 불러오게 합니다. 원본 DOM을 지우지 않기 때문에 X의 무한
스크롤이 계속 동작합니다.

주소가 바뀌는지는 0.4초마다 확인합니다. 콘텐츠 스크립트는 페이지 쪽 `history.pushState`
호출을 가로챌 수 없어서 이 방식을 씁니다.

## 폴더

```
manifest.json      확장 설정
src/core.js        설정, 저장소, 유틸
src/scraper.js     X의 DOM에서 값 뽑기
src/actions.js     좋아요, 리트윗, X 검색, 새 글/인용 리트윗 글 대신 입력·게시
src/update.js      GitHub에서 새 버전이 나왔는지 확인
src/grid.js        표 그리기, 선택, 정렬, 찾기, 복사, 우클릭 메뉴, 미디어 미리보기
src/chrome-ui.js   제목, 메뉴, 도구, 수식 입력줄, 상태 표시줄, 시트 탭
src/main.js        붙이고 떼기, 주소/탭 감시, 더 읽기, 시트 전환
src/styles.css     화면 스타일
popup/             설정 창
test/preview.html  브라우저에서 여는 미리보기 (X 없이 확인)
test/run.js        jsdom 검사
```

## 확인

`test/preview.html` 을 브라우저로 열면 가짜 타임라인으로 화면을 볼 수 있습니다.

jsdom 검사는 다음과 같이 돌립니다.

```
npm install jsdom
node test/run.js
```

## 알아둘 점

- X가 화면 구조(`data-testid`)를 바꾸면 값이 비어 보일 수 있습니다. 그때는
  `src/scraper.js` 의 선택자만 고치면 됩니다.
- 답글, 재게시, 마음, 조회 수는 X가 화면에 표시한 문자열(`3.4만` 등) 그대로 담고,
  정렬할 때만 숫자로 바꿔 씁니다.
- 쪽지와 설정 화면에서는 표 화면을 띄우지 않습니다.
- 동영상/움짤 미리보기는 X가 재생 주소를 임시(`blob:`) 주소로만 내려줄 때는 재생되지
  않고 첫 장면 이미지만 보입니다. X 내부 재생기 구조에 따라 달라질 수 있습니다.
- 인용 리트윗 안의 정보는 "그 글 안에 작성자 표시가 두 번째로 나오는 지점"을 기준으로
  찾아냅니다. X가 인용 카드의 구조를 크게 바꾸면 인용 부분이 비어 보일 수 있습니다.
- 새 글 작성은 왼쪽 사이드바의 글쓰기 버튼(`SideNav_NewTweet_Button`)을 찾아서 누릅니다.
  못 찾으면 X의 작성 화면 주소로 바로 이동합니다.
